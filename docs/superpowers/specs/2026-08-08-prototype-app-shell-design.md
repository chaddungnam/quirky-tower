# Quirky Tower 프로토타입 앱 셸 설계

## 목표

앱 실행 직후 1.5초 이내의 시작 배너를 거쳐 홈으로 진입하고, 홈에서 플레이와 설정을 실제 버튼으로 오갈 수 있게 한다. 설정의 언어 선택과 게임 내 선택 팝업은 긴 번역에도 깨지지 않는 하나의 세로형 규칙을 사용한다.

## 선택한 구조

기존 `Main`을 화면 전환을 소유하는 앱 셸로 확장한다. `SplashScreen`, `HomeScreen`, `SettingsScreen`, 기존 `RunScreen`을 자식으로 두고 한 번에 하나만 표시한다. 화면 전환은 각 화면의 신호로만 연결한다.

Quirky Ball의 대형 `Home`, `Settings`, `GamePopup` 구현은 현재 프로젝트 의존성이 많아 복사하지 않는다. 기존 `AppTheme`, `DesignTokens`, `GameOverlay`를 재사용하고 Tower에 필요한 작은 화면만 새로 만든다.

## 시작 배너

- 전체 시작 연출은 1.5초이며 2초를 넘지 않는다.
- House Duck, Quirky Tower 제목, 짧은 진행 막대를 표시한다.
- 로고를 보여주기 위해 로딩을 인위적으로 지연하지 않는다.
- 완료 시 `finished` 신호를 보내 홈으로 전환한다.

## 홈

- 크림색 바탕에 타워 실루엣과 방송 조명을 그려 정적인 빈 화면처럼 보이지 않게 한다.
- 중앙에 게임명, 한 줄 설명, `PLAY`, `SETTINGS`를 세로로 배치한다.
- 버튼은 720×1280 기준 최소 높이 96px, 화면 좌우 여백 48px 이상을 지킨다.
- 랭킹, 계정, 상점, Supabase 상태는 아직 표시하지 않는다.

## 설정

- `BGM`, `SFX`, `진동`, `언어`와 `뒤로`만 제공한다.
- 실제 오디오·햅틱 시스템이 아직 없으므로 토글은 프로토타입 상태만 바꾸며 연동 완료로 표현하지 않는다.
- 언어는 Quirky Ball 공통 지원 범위인 한국어, 영어, 독일어, 일본어, 프랑스어, 스페인어, 이탈리아어, 중국어 간체·번체, 아랍어를 표시한다.
- 설정 행과 뒤로 버튼은 세로 스크롤 안에 배치해 작은 화면과 긴 번역에 대응한다.

## 선택 팝업 공통 규칙

- 선택 버튼은 개수와 관계없이 항상 `VBoxContainer`에 세로로 놓는다.
- 버튼 텍스트는 단어 단위 줄바꿈을 켜고 최소 높이 96px를 유지한다.
- 선택 목록은 `ScrollContainer` 안에서 스크롤된다.
- 닫기 경로가 필요할 때도 마지막 세로 버튼으로 제공한다.
- 언어 선택, Quirk 선택, 런 종료의 `다시 플레이/홈`이 같은 규칙을 사용한다.

## 앱 흐름

```text
시작 배너
  -> 홈
     -> 플레이 -> 기존 15층 런 -> 다시 플레이 또는 홈
     -> 설정 -> 언어 세로 선택 팝업 -> 설정 -> 홈
```

## 검증

- 헤드리스 테스트로 시작 화면, 홈 전환, 설정 진입, 독일어 전환, 플레이 진입을 확인한다.
- 긴 독일어 선택지로 모든 선택 버튼이 세로·줄바꿈·최소 터치 높이를 지키는지 확인한다.
- 실제 360×640 창에서 홈과 독일어 설정을 캡처하고 버튼 좌표로 홈·설정·언어·플레이를 이동한다.
- macOS 화면 검증을 Android/iOS 안전 영역과 실제 손가락 검증으로 과장하지 않는다.

## 제외

Supabase, 계정, 랭킹 네트워크, 실제 광고·결제, 실제 오디오·햅틱 적용, 설정 저장, 최종 아트는 이번 범위에서 제외한다.
