# 게임 규칙

- 한 런은 15층이다.
- 층마다 `Timing Ring -> Tap Panic -> Drag Dodge`가 순서대로 바뀐다.
- 한 층은 `0.72초 예고 -> 즉시 플레이 -> 0.68초 결과 -> 다음 층`으로 진행하며 층마다 계속 버튼을 누르지 않는다.
- Timing Ring은 회전 바늘이 꼭대기 목표 구간에 들어왔을 때 탭한다.
- Tap Panic은 3×4 색·도형 판에서 라임 원만 연속으로 찾는다.
- Drag Dodge는 고정 사선 카메라의 2.5D 방송 복도에서 벽을 드래그로 피한다. 플레이어는 2D 픽셀 진행자지만 `CharacterBody3D`와 실제 콜라이더로 움직인다.
- 저폴리 벽은 먼 깊이에서 작게 등장해 다가올수록 커진다. `Area3D`와 실제로 겹치면 `BONK`, 통과하면 벽이 찌그러져 사라지며 `DODGE` 또는 `NEAR MISS`를 표시한다.
- 기본 하트는 3개다.
- 성공하면 점수와 콤보가 오르고 다음 층으로 간다.
- 실패하면 콤보가 끊기고 하트를 잃으며 같은 층에 재도전한다.
- 5·10·15층은 체크포인트와 스토리 지점이다.
- 4·8·12층에서 아직 보유하지 않은 Quirk를 하나 고른다.

Quirk는 `wide_window`, `overheat_combo`, `replay`, `reroute` 4종이다. 모든 조정값은 `data/` JSON에서 관리한다.

국가와 유머성 소속은 하나의 목록에서 고르는 단일 `country` 코드다. UI 명칭은 항상 `국가/소속`을 사용한다.
