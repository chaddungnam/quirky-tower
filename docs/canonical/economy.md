# BM

Pay-to-win 효과를 허용한다. Sponsor Boost는 한 런에 1회, 하루 5회가 초기 제한이다.

- 보상형 광고와 유료 티켓은 같은 게임 내 효과를 준다.
- 현재 효과는 하트 +1이다.
- 광고 제거 이용자도 같은 제한을 받는다.
- 정상적인 Boost 사용자는 별도 랭킹으로 분리하지 않는다.
- 광고/결제 출처는 분석용으로만 남기고 게임 판정에는 사용하지 않는다.

10,000런에서 무지원 완주율은 52.07%, 광고와 결제는 각각 55.63%였다. 이는 초기 시뮬레이션 값이며 실제 손맛과 수익화 SDK 동작을 증명하지 않는다.
