# 디자인 정책

UI는 다음 세 층으로만 공통화한다.

1. `AppTheme.tres`: 폰트와 Godot 컨트롤 기본 스타일
2. `DesignTokens`: 색 역할, 간격, 반경, 글자 크기, 애니메이션 시간
3. 공통 컴포넌트: 버튼, 카드, 팝업, 탭, 칩, 랭킹 행

개별 화면에 색상, 글자 크기, 모서리 값을 직접 넣지 않는다. Quirky Ball 코드는 실제로 두 게임에서 재사용되는 부분만 작은 단위로 옮긴다.

현재 최소 플레이 UI는 `AppTheme.tres`, `DesignTokens`, `RunHud`, `GameOverlay`를 사용한다. 색 역할은 먹색 `BACKGROUND`, 남청 `SURFACE`, 상아 `TEXT`, 라임 `PRIMARY`, 청록 `SECONDARY`, 복숭아 `WARNING`, 연보라 `SECRET`, 적색 `DANGER`다. 기존 색 이름은 오래된 프로토타입 씬을 같은 팔레트로 유지하는 호환 별칭이다.

제목과 고정 방송 표기는 House Duck이 이미 보관한 SIL OFL `Do Hyeon`을 재사용한다. 번역 본문과 선택 버튼은 긴 독일어·아랍어 등의 fallback을 위해 기본 UI 폰트를 유지한다. 최종 생산 UI와 캐릭터 아트는 아직 확정하지 않았다.

## 2.5D 무대

- 고정 직교 사선 카메라, 저폴리 기본 메시, 픽셀 `Sprite3D`, 실제 3D 콜라이더만 사용한다.
- 외부 3D 플러그인, 셰이더, 모델 에셋은 현재 수직 슬라이스에 추가하지 않는다.
- 배경은 가장 어둡게, 플레이면은 중간, 플레이어·위험물은 가장 밝게 유지해 색을 빼도 층이 읽히게 한다.
- 2.5D 무대는 Drag Dodge에만 사용한다. 다른 두 게임은 같은 층에서 덧붙이지 않는다.
- 벽 충돌은 적색 플래시와 `BONK`, 회피는 벽 축소·소멸과 `DODGE`, 근접 회피는 `NEAR MISS`로 구분한다.

## 인게임 전환과 마스코트

- 각 층은 짧은 모드 카드와 마스코트 말풍선으로 시작하고, 조작 중에는 둘 다 빠져 플레이를 가리지 않는다.
- 결과는 `CLEAR` 또는 `BONK` 카드, 화면 플래시, 파티클, 마스코트 반응을 0.68초 동안 보여준 뒤 자동 진행한다.
- 시스템 결과 문구와 마스코트 대사를 중복하지 않는다. 말풍선은 한 문장만 사용한다.
- 공통 팝업은 카드가 튀어 오르고 선택 버튼이 위에서 아래로 차례로 등장한다.

## 프로토타입 앱 셸

- 앱 시작 배너는 House Duck과 Quirky Tower를 표시하고 1.5초 안에 홈으로 넘어간다.
- 홈은 타워와 방송 조명이 움직이는 배경, 게임명, 플레이, 설정을 사용한다.
- 설정은 BGM, 효과음, 진동, 언어, 홈으로의 복귀를 세로로 배치한다. 실제 오디오·햅틱 연동 전까지는 프로토타입 상태만 바꾼다.
- 기본 언어는 기기 로케일을 따르며 `ko`, `en`, `de`, `ja`, `fr`, `es`, `it`, `zh_CN`, `zh_TW`, `ar`와 영어 fallback을 제공한다.

## 선택 팝업

- 선택 버튼은 개수와 관계없이 항상 하나의 `VBoxContainer`에 세로로 배치한다.
- 번역 길이에 대응하도록 단어 단위 줄바꿈과 96px 최소 터치 높이를 공통 적용한다.
- 목록은 `ScrollContainer` 안에서 움직이며 가로 스크롤은 사용하지 않는다.
- 취소가 가능한 팝업은 마지막 세로 버튼으로 닫기 경로를 제공한다.
- 이 규칙은 언어, Quirk, 런 종료의 다시 플레이·홈 선택에 공통 적용한다.
