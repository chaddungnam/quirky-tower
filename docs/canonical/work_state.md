# 현재 작업 상태

- 현재: 시작 배너에서 홈으로 진입해 설정 또는 통합 15층 런을 선택하는 프로토타입. 사람의 재미 평가는 아직 필요하다.
- 포함: 1.5초 시작 배너, 움직이는 홈, 프로토타입 설정, 10개 언어, 세로형 번역 대응 선택 팝업, 층별 3경로 선택, 3초 직접 회피, 타이밍 파괴, 위험 점수 배수, 파편 피드백, Quirk 4종, 스토리 3비트, 게임오버·재시작, Sponsor Boost 동등성, 국가/소속 단일 코드
- 수정: 결과 버튼 신호 중 버튼을 즉시 해제해 발생하던 Godot locked object 크래시 제거
- 수정: 숨은 런을 홈에서 재시작할 때 도전 씬 이름이 임시 이름으로 남던 정리 결함 제거
- 검증: 앱 시작·홈·설정·독일어 전환·홈 복귀·인게임 진입, 메인 씬·자동 15층 상태 흐름·실제 경로 선택/드래그/파괴/결과/2층 진입·고정 시드 스모크·10,000런 PASS
- 도구: Context7 미사용, 공식 Godot MCP 0.7.2 및 Godot 4.7 로컬 문서 검색 적용
- 관측 완주율: 무지원 52.07%, 광고 55.63%, 결제 55.63%
- 미검증: 사용자 입력만으로 15층 완주, 최종 UI·아트, 설정 저장과 실제 오디오·햅틱, Android/iOS, 광고·결제·Supabase 실연동
- 다음 P0: 사용자가 첫 30초와 한 런을 플레이한 뒤 조작·난이도·카타르시스 피드백 반영

## 작업 규칙

- 완료된 프로젝트 작업은 별도 질문 없이 커밋하고 `origin/main`에 푸시한다.
- 한 번에 하나의 P0만 진행한다.
- 현재 규칙과 과거 작업 로그를 같은 문서에 누적하지 않는다.
